# Fake News Detection System

## Overview
This project detects whether a news article is REAL or FAKE using Machine Learning and NLP techniques.

## Features
- GUI based interface
- Fake/Real prediction
- News text analysis
- Machine Learning model

## Technologies Used
- Python
- Tkinter
- Pandas
- Scikit-learn
- NLP

## Dataset
Dataset contains:
- Fake news
- True news

## How to Run

Install libraries:

```bash
pip install -r requirements.txt
```

Run project:

```bash
python gui.py
```
